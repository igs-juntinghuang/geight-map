# G-EIGHT 2026 展場地圖（加強版）

G-EIGHT 2026 展場地圖（map.geight.io）的個人研究加強版。攤位圖片（kv/）與活動內容版權屬 G-EIGHT 與各參展商。

## 開啟
- 雙擊 `啟動.bat`（需要 Python），或在此資料夾執行 `python start.py`，會開 http://127.0.0.1:8080/index.html。
- 不能直接雙擊 index.html：瀏覽器不允許 file:// 載入貼圖，會顯示改用 `啟動.bat` 的提示（原站同樣載不了）。
- 網址加 `?perf=off` 可關閉自動效能分級；`?debug=1` 顯示 fps；`?x=occ,props,mm,shadow,ui` 可個別關掉加強功能來比較效能。

## 操作
| 功能 | 操作 |
|---|---|
| 移動／跳 | WASD 或方向鍵／Space |
| 互動（攤位、商店、國王企鵝…） | **F**（原本的 E 已讓給轉向） |
| 轉方向 | **Q／E** 連續轉 |
| 俯仰、左右轉 | 滑鼠左／右鍵拖曳；觸控單指拖曳（雙指捏合＝縮放） |
| 視角切換（左上角） | 跟隨／俯瞰／近景／第一人稱，或按 V 輪替 |
| 小地圖（右上角） | 分區標色、霸姬位置與面向、鏡頭視野（藍色扇形） |

原站的 Z／X 轉 90° 與下方的「左轉」「右轉」按鈕已移除。

## 內容
- 新增模型（程式建構、合併成 4 塊）：遊戲機台、長椅、分區色旗桿、冰晶。沒有任何過年元素。
- 主角：維持原站的 2D 立牌（貼圖與材質不變），只依鏡頭俯角調整傾斜，任何角度看起來一樣高。
- 遮蔽：主角被牆或攤位擋住時，擋在中間的那幾個物件變半透明；地面與地形不參與，不會破圖。
- 鏡頭：壓到平視時自動限制距離、不退到台地外、不鑽到地面下。
- 離線：three.js r128 與字型 DotGothic16 都在本機（vendor/、fonts/）。
- 跑順：陰影圖隔幀更新且光源對齊格子、遮蔽射線每 3 幀一條並先用包圍盒預篩、小地圖只在有變化時重畫、自動效能分級（先降陰影、再降解析度，穩定後升回）。
