# G-EIGHT 2026 展場地圖（本機離線加強版）

G-EIGHT 2026 展場地圖（map.geight.io）的個人研究加強版。攤位圖片（kv/）與活動內容版權屬 G-EIGHT 與各參展商。

## 開啟
- 雙擊 `啟動.bat`（需要 Python），或在此資料夾執行 `python start.py`，會開 http://127.0.0.1:8080/index.html。
- 不能直接雙擊 index.html：瀏覽器不允許 file:// 載入貼圖，會顯示「霸姬的圖片載入失敗」（原站同樣）。
- 網址加 `?perf=off` 可關閉自動效能分級；`?debug=1` 顯示 fps。

## 操作
| 功能 | 操作 |
|---|---|
| 移動／跳 | WASD 或方向鍵／Space |
| 互動（攤位、商店、國王企鵝…） | **F**（原本的 E 已讓給轉向） |
| 轉方向 | **Q／E** 連續轉；Z／X 轉 90° |
| 俯仰、左右轉 | 滑鼠左／右鍵拖曳；觸控單指拖曳（雙指捏合＝縮放） |
| 視角切換（左上角） | 跟隨／俯瞰／近景／第一人稱，或按 V 輪替 |
| 小地圖（右上角） | 分區標色、霸姬位置與面向、鏡頭視野（藍色扇形） |

## 內容
- 新增模型（程式建構、分塊合併）：遊戲機台、長椅、分區色旗桿、冰晶。沒有任何過年元素（燈籠、牌樓、石獅、盆樹都已移除）。
- 主角：Hunyuan3D-2 由 `baji.webp` 單張正面圖生成的 3D 模型（`assets/baji3d.glb`，用本機的 `vendor/GLTFLoader.js` 載入），身體會朝行進方向轉。載入失敗或網址加 `?baji=2d` 時，退回沿貼圖輪廓擠出厚度的立牌。
- 遮蔽：主角被牆或攤位擋住時，鏡頭的近裁面會推到主角前方，等於穿過遮蔽物看。
- 離線：three.js r128 與字型 DotGothic16 都在本機（vendor/、fonts/）。
- 效能：自動分級（先降陰影、再降解析度，穩定後升回）、模型分塊裁切。
